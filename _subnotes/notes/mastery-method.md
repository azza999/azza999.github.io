## 내 것이 됐다는 기준

**자료를 덮고 설명할 수 있는가, 비슷한 개념을 구분하는가, 새로운 상황에 적용하는가, 다른 날에도 다시 할 수 있는가.**

이 네 가지를 확인한다. 지금 읽으면서 익숙하게 느끼는 것과, 필요할 때 꺼내 쓰는 능력은 다르다. 한 번의 정답으로 영구적인 완성을 선언하기보다 반복해서 확인한다.

각 노트는 `쉬운 설명 → 답안 핵심 → 도식·표 → 가리고 설명 → 상황 적용 → 혼동 교정 → 출처` 순서다. 처음부터 문장 전체를 외우지 말고, 원리를 이해한 뒤 핵심 용어를 정확하게 꺼내 쓴다.

## 한 토픽을 공부하는 순서

1. **이해:** 먼저 이해하기를 읽고 “왜 이 개념이 필요한가?”를 한 문장으로 말한다.
2. **구조:** 정의·회상 단서·표를 읽고, 도식을 빈 종이에 직접 그린다.
3. **회상:** 본문을 가리고 질문 두 개에 답한다. 말이 막힌 지점을 그대로 적는다.
4. **교정:** 접힌 정답을 열어 비교한다. 빠진 키워드·관계·오개념만 고친다.
5. **전이:** 상황 문제에 먼저 답한 뒤 풀이를 연다. 정답 문구보다 판단 근거를 비교한다.
6. **재현:** 다음 날 같은 토픽을 다시 설명한다. 이때는 읽기 전에 먼저 답한다.

한 번에 4개 정도를 하나의 묶음으로 시작해보자. 4개는 운영을 위한 시작값이며, 시간과 난도에 맞춰 조정한다. 이미 잘 아는 토픽은 먼저 질문을 풀고 필요한 부분만 읽는다.

## 기억에 남도록 다시 만나는 간격

| 시점 | 먼저 할 것 | 막히면 할 것 |
| --- | --- | --- |
| 처음 공부한 날 | 읽고 구조 이해, 가리고 설명 | 해당 부분만 다시 읽고 바로 재시도 |
| 다음 날 | 정의·그림·비교를 먼저 회상 | 빠진 관계·용어만 교정 |
| 약 3일 뒤 | 다른 개념과 섞어 비교 | 혼동한 쌍을 붙여서 연습 |
| 약 7일 뒤 | 새 상황으로 질문·답안 구성 | 적용 근거를 다시 확인 |
| 약 14일 뒤 | 시간 제한을 두고 답안 작성 | 목차·핵심 누락을 보완 |

이 간격은 **개인 운영을 위한 제안**이다. 연구가 모든 사람에게 “1·3·7·14일”을 보편적 최적값으로 정한 것은 아니다. 틀리면 더 이른 시점에 다시 만나고, 안정적이면 간격을 늘린다.

자료를 반복해서 읽기만 하는 것보다 기억에서 답을 꺼내는 연습과 간격을 둔 복습을 포함한다. 정답 확인 후에는 스스로 다시 답해, 방금 읽은 설명을 따라 말하는 데서 끝나지 않도록 한다.

## 셀프테스트로 연결하기

| 과제 | 확인 기준 |
| --- | --- |
| 정의 | 본질과 핵심 용어를 빠뜨리지 않고 내 말로 설명 |
| 도식 | 구성요소뿐 아니라 관계·흐름·시간 방향 표현 |
| 비교 | 같은 축으로 차이를 설명하고 사례로 구분 |
| 적용 | 문제의 조건을 근거로 선택·계산·대응 설명 |

1교시형 연습은 **정의·핵심 구조·비교 또는 유의점**으로 짧게 구성한다. 수업 지시에 따라 기대효과를 관성적으로 붙이지 않는다. 2교시형에서는 질문이 요구한 절차·대책·효과 등으로 목차를 확장한다.

노트의 목차를 그대로 옮기지 말고 **문제에서 실제로 물은 것**을 답한다. “공유경제를 설명하라”와 “공유경제의 신뢰 문제와 대응을 설명하라”의 중심은 다르다.

## 나와 대화로 복습하는 방법

이렇게 요청하면 된다.

> “오늘은 업무연속성 4개를 문제만 내줘. 한 문제씩 답할게. 틀리면 힌트를 주고 마지막에 다시 물어봐.”

> “RTO·RPO·DRP·DRS를 섞어서 상황 문제로 확인해줘. 처음에는 정답을 보여주지 마.”

> “내 답에서 빠진 키워드와 잘못된 관계만 교정해줘. 외운 문장과 달라도 의미가 맞는지 봐줘.”

답변에서 확인된 오개념·누락을 해당 노트에 반영한다. 노트를 만들었다는 이유만으로 학습 점수를 올리지 않는다. 실제 답변과 요청 범위를 기준으로 기존 평가 절차를 따른다.
