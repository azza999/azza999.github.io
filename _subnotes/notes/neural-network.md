## 먼저 이해하기

신경망은 사람이 모든 판단 규칙을 직접 작성하는 대신, 예측과 정답의 차이를 줄이도록 연결의 가중치를 조정한다. 층을 쌓아 복잡한 관계를 표현할 수 있지만 데이터와 평가가 뒷받침되어야 한다.

## 답안에 남길 핵심

**정의:** 인공신경망은 입력의 가중합과 활성화함수로 구성된 계산 단위를 연결하고, 손실을 줄이도록 가중치·편향을 학습하여 분류·예측 등의 함수를 근사하는 모델이다.

**회상 단서:** 입력층·은닉층·출력층 · 가중치·편향 · 활성화 · 손실 · 역전파

## 구조와 학습

```text
입력 x → 가중합(Wx+b) → 활성화 → 다음 층 → 예측
                                         ↓
가중치 갱신 ← 기울기·역전파 ← 손실(예측과 정답 비교)
```

| 요소 | 역할 |
| --- | --- |
| 가중치·편향 | 관계의 강도와 기준을 조정 |
| 활성화함수 | 비선형성 부여. ReLU·sigmoid 등 |
| 손실함수 | 예측이 얼마나 틀렸는지 측정 |
| 역전파 | 손실의 기울기를 각 파라미터로 전달 |
| 최적화 | 기울기 등을 이용해 파라미터 갱신 |

활성화 없이 선형 층만 합성하면 전체도 선형 변환이다. 비선형 활성화가 복잡한 관계 표현에 중요하다. 검증 데이터·정규화·조기 종료 등으로 과적합을 점검한다.

## 가리고 설명하기

본문을 위로 올려 가린 뒤, 말하거나 빈 종이에 적는다. 정답을 읽기 전에 답한다.

1. 역전파와 추론을 구분해보자.
2. 은닉층만 많이 늘리면 항상 좋아질까?

<details class="answer" markdown="1">
<summary>내 답과 비교할 기준</summary>
<div markdown="1">

**1.** 추론은 학습된 가중치로 출력을 계산한다. 역전파는 학습 시 손실 기울기를 계산해 갱신을 지원한다.

**2.** 아니다. 데이터·학습·복잡도에 따라 과적합·비용·학습 불안정이 생길 수 있다.

</div>
</details>

## 상황에 적용하기

학습 정확도 99%, 새로운 데이터 정확도 65%다. 무엇을 의심하고 확인할까?

<details class="answer" markdown="1">
<summary>풀이와 판단 근거</summary>
<div markdown="1">

과적합, 학습·운영 데이터 차이, 누수·레이블 품질을 확인한다. 검증·시험 분리, 정규화·모델 복잡도 조정, 대표성 있는 데이터로 개선하고 다시 평가한다.

</div>
</details>

## 헷갈리지 않기

“사람 뇌와 완전히 동일하게 작동한다”고 쓰지 않는다. sigmoid가 모든 층의 정답도 아니다. 함수는 역할·출력 범위·학습 특성에 맞게 선택한다.
