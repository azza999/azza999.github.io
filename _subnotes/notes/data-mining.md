## 먼저 이해하기

“빵을 산 고객은 우유도 많이 산다”는 말을 검증하려면 전체 거래·빵 거래·우유 거래·동시 구매를 비교해야 한다. 데이터 마이닝은 이런 패턴이나 예측 모델을 찾아 의사결정에 활용한다.

## 답안에 남길 핵심

**정의:** 데이터 마이닝은 데이터에서 유의미한 패턴·연관관계·규칙 또는 예측 모델을 발견하고 평가하는 분석 활동이다. KDD는 선택·전처리·변환·마이닝·평가를 포함하는 더 넓은 지식발견 과정이다.

**회상 단서:** 분류 · 회귀 · 군집 · 연관 / 지지도·신뢰도·향상도 / 평가

## 기법과 연관규칙

| 기법 | 질문 |
| --- | --- |
| 분류 | 기존 레이블 중 어디에 속하나? |
| 회귀 | 연속값이 얼마인가? |
| 군집 | 레이블 없이 어떤 집단이 나타나나? |
| 연관규칙 | 어떤 항목이 함께 발생하나? |

100건 중 빵(A) 20건, 우유(B) 30건, 동시 구매 12건이라면:

- 지지도 P(A∩B) = 12/100 = **12%**.
- 신뢰도 P(B｜A) = 12/20 = **60%**.
- 향상도 P(B｜A)/P(B) = 0.6/0.3 = **2**.

```text
목적 → 데이터 선택·전처리 → 모델링 → 평가 → 활용
```

분류 평가에서는 혼동행렬의 TP·FP·FN·TN과 정밀도·재현율을 연결한다. 배깅은 표본 변화로 여러 모델을 결합하고, 부스팅은 이전 오류를 보완하는 방향으로 모델을 순차 결합한다.

## 가리고 설명하기

본문을 위로 올려 가린 뒤, 말하거나 빈 종이에 적는다. 정답을 읽기 전에 답한다.

1. 향상도 2는 원인·결과를 입증할까?
2. 분류와 군집의 차이는?

<details class="answer" markdown="1">
<summary>내 답과 비교할 기준</summary>
<div markdown="1">

**1.** 아니다. 우유의 일반 구매 비율보다 빵 구매 조건에서 우유 비율이 2배라는 연관이다.

**2.** 분류는 정해진 레이블을 학습, 군집은 레이블 없이 유사 집단을 발견한다.

</div>
</details>

## 상황에 적용하기

질병 사례가 1%인 데이터에서 항상 정상이라고 예측해 정확도 99%를 얻었다. 좋은 모델일까?

<details class="answer" markdown="1">
<summary>풀이와 판단 근거</summary>
<div markdown="1">

실제 질병을 전부 놓치므로 재현율은 0이다. 혼동행렬을 보고 오탐·미탐 비용과 목적에 맞게 평가해야 한다. 정확도 하나로 결론 내리지 않는다.

</div>
</details>

## 헷갈리지 않기

데이터는 Data Lake에서만 오는 것이 아니다. 학습·평가 데이터를 분리해 누수를 막고, 연관을 인과관계로 쓰지 않는다. 수업에서는 연관지표 이해와 모델링·평가를 우선한다.
