# 기술사 학습 대시보드
분모 없는 누적 숙련도 점수와 한국시간 날짜별 성장을 보여주는 GitHub Pages 앱입니다. 서버·DB·별도 패키지 설치 없이 Python 표준 라이브러리로 빌드합니다.

## 사용 주소와 자동 배포
https://azza999.github.io/study/

기존 블로그의 Pages 배포가 완료된 뒤 전용 workflow가 기록을 재계산하고, 블로그 전체와 대시보드를 함께 게시합니다. 기존 Pages 설정은 그대로 사용합니다.

이 사이트는 공개이며 접근 제한 기능은 없습니다.

## 주제 추가와 점수 변경
`_study/topic-template.md`를 `_study/topics/my-topic.md`로 복사하고 제목, 영역, 점수, 본문을 작성해 커밋합니다. GitHub 웹 편집기로도 가능합니다.

```markdown
---
id: pqc
title: 양자내성암호
category: 디지털 시큐리티
score: 20
---
## 핵심 개념
여기에 내용을 작성합니다.
```

`id`는 주제마다 고유한 영문 식별자이며, 파일을 옮겨도 유지하세요. 점수는 0, 20, 40, 60, 80, 100만 허용합니다. 새 주제 0점 추가는 누적 점수를 낮추지 않습니다. 템플릿은 _study/topics 바깥에 있어 집계되지 않습니다.

| 점수 | 자기평가 기준 |
|---|---|
| 0 | 아직 공부 안 함 |
| 20 | 개념 이해 완료 |
| 40 | 간단하게 해당 개념 설명 가능 |
| 60 | 정의·특징·주요 내용으로 1교시형 답안 설명 가능 |
| 80 | 주어진 2교시+형 답안 구조의 빈칸 모두 완성 가능 |
| 100 | 스스로 답안 구조를 만들고 내용을 빠짐없이 완성 가능 |

## 기록 방식
별도 이력 파일을 쓰지 않습니다. 배포 시 전체 Git 커밋 기록을 읽어 각 시점의 점수를 재구성합니다. 한국시간 **커미터 날짜** 기준으로 같은 날 마지막 점수를 그래프에 표시합니다. 최근 변화에는 각각의 상승·하락을 표시하며 본문만 수정하면 점수 변화가 생기지 않습니다. 휴식일에는 마지막 점수가 유지됩니다. 삭제한 주제의 점수는 현재 합계에서 빠지며 기록에는 감소로 남습니다. 이름을 바꾸어도 id를 유지하면 같은 주제로 취급됩니다. master의 first-parent 이력을 사용하므로 PR merge는 합쳐진 시점에 기록합니다.

Git 이력을 squash/rebase/force-push하면 과거 그래프도 재구성됩니다. 장기 기록을 보존하려면 master의 과거 커밋을 유지하세요. 커밋 전 파일 수정은 기록되지 않습니다.

본문은 제목, 문단, 목록, 굵게, 인라인 코드, 코드 블록, 단순 표를 지원합니다. HTML은 실행하지 않고 문자로 표시합니다. 이미지·링크·수식 등 전체 Markdown 규격은 아직 지원하지 않습니다.

## 로컬 확인
```bash
python3 _study/scripts/build.py
python3 -m http.server 8000 --directory study
```
브라우저에서 http://localhost:8000 으로 확인합니다. Git 기록이 없으면 현재 점수만 표시합니다. 실제 커밋과 작업 중 파일이 다르면 현재 합계와 과거 그래프가 다를 수 있으나 배포본은 커밋 기준으로 일치합니다.
