## 핵심 개념
EVA(Earned Value Analysis)는 측정시점의 계획가치(PV), 획득가치(EV), 실제원가(AC)를 이용하여 일정·원가 성과를 분석한다.
- SV = EV - PV, SPI = EV / PV: 일정 성과
- CV = EV - AC, CPI = EV / AC: 원가 성과
- SPI < 1은 일정 지연, CPI < 1은 원가 초과.
- SPI는 금액 기반의 상대적 일정 성과를 나타내며 정확한 지연일수를 뜻하지 않음.
- 확장 개념: BAC(완료시점 예산), EAC(완료시점 원가 추정), ETC(잔여원가 추정), VAC(완료시점 원가 차이).

## 학습 사례
- PV 2억, EV 1.5억, AC 1.8억: SV -0.5억, SPI 0.75, CV -0.3억, CPI 5/6.
- PV 2.5억, EV 2억, AC 2.4억: SPI 0.8, CPI 5/6(약 0.833), 원가 초과.
- 측정시점의 PV는 시간별로 균일하게 증가하지 않으므로 SPI만으로 며칠 지연되었는지 판정할 수 없음.
