## 핵심 개념
- SCM(Software Configuration Management): 형상항목의 식별과 변경을 통제해 무결성·일관성을 유지.
- 4대 절차 '식통감기': 형상 식별 → 형상 통제 → 형상 감사 → 형상 기록(상태 보고).
- CR(Change Request) → 영향 분석 → CCB(Change Control Board) 심의 → 변경 수행 → 검증·기록.
- 기준선 5가지: 기능적(시스템 기능·성능) → 분배적(하위 컴포넌트에 요구사항 할당) → 설계 → 개발 → 제품.
- 버전관리: CVCS(중앙집중형, 예 SVN)는 중앙 저장소에 이력 집중, DVCS(분산형, 예 Git)는 개발자별 로컬 저장소에 이력 보유. 구분은 소프트웨어의 기능 분리가 아니라 변경 이력의 저장·협업 구조.
- Git의 add/commit/pull/push/branch/merge를 이해하며 버전관리는 SCM의 일부.

## 강의 기준
- 2주차 전사본 음성 2 '형상관리와 기준선', '버전관리와 Git'; 형상관리 답안 준비, 기준선 단계 구분, 버전관리 명령어 중심.

## 평가 기록
