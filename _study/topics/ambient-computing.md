## 핵심 개념
- 앰비언트 컴퓨팅(Ambient Computing): 컴퓨팅 기술이 일상 환경에 자연스럽게 내재화되어, 사용자의 명시적 조작을 최소화하고 상황을 인식해 지능형 서비스를 제공하는 컴퓨팅 패러다임.
- 핵심 가치: 비가시성, 자연스러운 상호작용, 상황 인식, 선제적 서비스, 사용자 중심성.

## 구성요소 및 동작 절차
- 구성요소: IoT 센서, 네트워크, 상황 인식(Context Awareness) 엔진, AI 추론, 엣지·클라우드 컴퓨팅, 서비스 실행 장치.
- 동작 절차: 센싱 → 상태 추적 → 상황 인식·추론 → 의사결정 → 서비스 제공 → 피드백.
- Zero UI(Zero User Interface): 화면·버튼 등의 명시적 조작을 줄이고 음성·제스처·상황 인식 등으로 상호작용하는 인터페이스 개념.
- 햅틱 피드백(Haptic Feedback)은 촉각 기반 출력·피드백 수단으로 Zero UI 환경에서 활용할 수 있으나 Zero UI의 필수 요소는 아님.

|---|---|---|
| 유비쿼터스 컴퓨팅 | 언제 어디서나 컴퓨팅 이용 | 접근성·연결성 |
| IoT | 사물과 센서의 연결·데이터 수집 | 장치 중심 |
| 앰비언트 컴퓨팅 | 자연스럽게 내재화된 지능형 환경 | 상황 인식·자동화 |
| 앰비언트 커머스 | 생활 속 상거래의 자연스러운 통합 | 구매 마찰·개입 최소화 |

## 적용 및 고려사항
- 스마트홈의 재실 감지 기반 조명·냉난방 제어, 차량의 운전자 상태 기반 맞춤 제어, 스마트팩토리의 환경·설비 상태 기반 대응.
- 보안·개인정보 보호: 상시 센싱에 따른 최소 수집, 사용자 동의·제어, 기기 인증, 엣지 처리, 접근통제.
