## 핵심 개념
- 반정규화: 조회 성능과 처리 효율을 높이기 위해 정규화된 데이터 모델에 데이터 중복, 테이블 병합·분할, 관계 재구성 등을 의도적으로 적용하는 설계 기법.
- 목적: 반복 JOIN 감소, 조회 응답시간 단축, 복잡한 쿼리 단순화.
- 고려사항: 데이터 중복, 갱신 이상, 정합성 관리, 저장 공간 증가. 성능 병목 확인 후 적용.

## 적용 배경
- 조회 횟수·조회 범위 증가, 복잡한 데이터 관계
- 디스크 I/O 증가, 조회 속도 감소, 쿼리문 복잡도 증가

## 반정규화 적용 기법
| 측면 | 기법 | 예시 |
|---|---|---|
| 테이블 | 병합 | 고객 + 주문을 하나의 테이블로 결합 |
| 테이블 | 수평 분할 | 주문내역 → 주문내역_2025, 주문내역_2026 |
| 테이블 | 수직 분할 | 주문내역 → 주문내역, 주문내역_상세 |
| 테이블 | 추가 | 주문 데이터를 기반으로 주문통계 테이블 추가 |
| 컬럼 | 중복 컬럼 | 주문에 고객명을 중복 보관 |
| 컬럼 | 파생 컬럼 | 단가·수량으로 계산한 총액을 저장 |
| 컬럼 | 이력 컬럼 | 현재 값과 이전 값을 보존하는 이력 속성 추가 |
| 관계 | 조인 경로 단축 | 사원 → 부서 → 본부 대신 사원 → 본부 직접 참조 추가 |
| 관계 | 중간 테이블 추가 | 학생 → 수강신청 → 강의 → 교수의 반복 조회를 위해 학생별담당교수 관계 테이블 구성 |

## 관계 측면 비교
- 조인 경로 단축: 중간 테이블을 거치지 않고 기존 테이블 간 직접 참조 관계를 추가.
- 중간 테이블 추가: 자주 사용하는 연결 정보를 별도 테이블에 미리 저장해 반복적인 다단계 JOIN을 줄임.
- 주의: '테이블 추가'와 구현이 겹칠 수 있으나 분류상 관계 측면은 JOIN 경로·연결 구조 개선에 초점.

## 답안 구조
1. 반정규화 정의·적용 배경
2. 테이블 측면: 병합 / 수평·수직 분할 / 추가
3. 컬럼 측면: 중복 / 파생 / 이력
4. 관계 측면: 조인 경로 단축 / 중간 테이블 추가
5. 효과·유의사항: 조회 성능 향상 vs 중복·갱신·정합성 부담
