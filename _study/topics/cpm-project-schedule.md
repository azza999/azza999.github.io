## 핵심 개념
CPM(Critical Path Method): 선후행 관계와 활동기간으로 전체 프로젝트 기간을 결정하는 경로를 분석하는 기법.
- 주공정 경로(Critical Path): 총여유시간(Total Float)이 0인 활동을 연결한 경로.
- 비주공정 활동의 지연은 여유시간 범위 내에서는 전체 종료일을 바꾸지 않을 수 있음.

## 학습 사례
- A 5일, B 7일(A 후), C 4일(A 후), D 3일(B·C 후)
- A→B→D = 15일(주공정), A→C→D = 12일(여유 3일)
- C가 6일이면 전체 15일 유지, C가 8일이면 A→C→D = 16일로 주공정 변경.
