## 핵심 개념
- 데이터 마이닝(Data Mining): 대용량 데이터에서 유의미한 패턴, 연관관계, 규칙을 발견하여 의사결정에 활용하는 분석 기법.
- KDD(Knowledge Discovery in Databases)는 전체 지식발견 과정이며, 데이터 마이닝은 그중 패턴 탐색·모델링 단계에 해당한다.

## 주요 절차
선택 → 전처리 → 변환 → 데이터 마이닝(모델링) → 평가·해석.

## 대표 분석 기법
| 기법 | 핵심 개념 | 활용 |
|---|---|---|
| 연관규칙(Association Rule) | 함께 발생하는 항목의 관계 발견 | 장바구니 분석 |
| 순차패턴(Sequence Pattern) | 시간적 선후관계에 따른 빈번한 패턴 발견 | 구매 순서 분석 |
| 군집화(Clustering) | 레이블 없이 유사도 기반 집단 발견 | 고객 소비 집단 탐색 |
| 분류(Classification) | 학습된 레이블 기반 클래스 예측 | 신규 고객의 소속 분류 |
| 회귀(Regression) | 연속형 수치 예측 | 수요·매출 예측 |
| 의사결정트리(Decision Tree) | 조건 분기 및 불순도 감소 기반 분류·예측 | 이탈 여부 판별 |

## 학습 내용
- 연관규칙은 동시 발생 관계, 순차패턴은 시간 순서를 반영한 발생 관계로 구분. 순차패턴 알고리즘 GSP, SPADE, PrefixSpan 학습.
- 군집화는 비지도학습이며 데이터로부터 집단 자체를 발견. K-means, DBSCAN 등.
- 분류는 지도학습이며 사전에 정의된 클래스를 학습하여 신규 데이터를 해당 클래스로 예측. 의사결정트리, SVM, 랜덤 포레스트 등.
- 의사결정트리의 반복적 조건 분기, 엔트로피와 정보이득 개념 학습.
- 답안 작성 시 표·도식 중심, 데이터 마이닝과 KDD의 경계 및 분석 기법의 분류 체계를 구분할 필요가 있음.
