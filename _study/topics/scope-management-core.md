## 핵심 개념 및 절차
범위관리 6개 프로세스는 PMBOK 6판의 49개 관리 프로세스 안에 포함된다.
- 암기: 계요정작확통 = 범위관리 계획 수립 → 요구사항 수집 → 범위 정의 → WBS 작성 → 범위 확인 → 범위 통제.
- 계획 그룹: 계·요·정·작 / 감시 및 통제 그룹: 확·통.
- 각 산출물: 범위·요구사항 관리계획서 → 요구사항 문서·추적 매트릭스 → 프로젝트 범위기술서 → 범위기준선 → 승인된 인도물 → 변경요청(CR).

## 요구사항 수집(Collect Requirements) ITO
- Input: 프로젝트 헌장, 프로젝트 관리계획서, 프로젝트 문서, 비즈니스 문서, 협약서, EEF, OPA.
- Tools & Techniques: 전문가 판단, 자료 수집(브레인스토밍, 인터뷰, 핵심전문가 그룹, 설문, 벤치마킹), 데이터 분석, 의사결정, 데이터 표현, 대인관계·팀 기술, 컨텍스트 다이어그램, 프로토타입.
- Output: 요구사항 문서 ★, 요구사항 추적 매트릭스(RTM) ★★.
- RTM(Requirements Traceability Matrix): 요구사항을 설계·개발·시험 산출물과 연결하여 누락과 변경 영향을 추적.

## 강사 지시·학습 범위
- 강사는 범위관리 6개 프로세스의 명칭과 순서를 암기하라고 명시.
- 요구사항 수집 기법은 대표 약 5개를 답안에 활용, 전체 하위 목록은 암기 제외.
- 참고: ITPE 프로젝트관리 V6.2, 33~35·39쪽, 2주차 강의 전사본.
