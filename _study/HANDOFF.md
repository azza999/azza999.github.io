# 다른 대화에서 학습 기록 반영하기

정보관리기술사 공부 결과를 `azza999/azza999.github.io` 저장소의 `master`에 반영해줘.

- 먼저 이 파일과 현재 `_study/topics/`를 읽고 중복 주제를 확인해. 주제 하나당 `_study/topics/<영문-id>.md`에 핵심 요약·답안 구조·출처를 짧게 기록해. 기존 본문과 고유 id는 유지해.
- 상단 메타데이터는 `id`, `title`, `category`, `score`, `max_score`를 사용해. score는 0~max_score 사이 임의의 정수야. 1교시형 중심 주제는 max_score 60, 2교시 이상 확장형은 100을 기본으로 두되 내가 정한 범위·강사 지시를 우선해.
- 점수 참고 기준: 0 미학습, 20 개념 이해, 40 간단한 설명 가능, 60 정의·특징·핵심 내용으로 1교시형 답안 작성 가능, 80 주어진 2교시+형 답안 구조 완성 가능, 100 구조부터 내용까지 스스로 완성 가능. 중간 점수는 내가 자유롭게 정해. 학습 내용을 듣거나 노트를 만든 것만으로 점수를 자동 부여하지 말고, 내 자기평가를 받아. 내가 요청할 때만 짧은 질문으로 평가를 도와줘.
- 내가 점수와 최대 점수를 주면 파일을 수정하고 커밋해. 새 주제 0점 추가, 점수 하향 조정도 가능하며 최대 점수 변경만으로 현재 점수를 변경하지 마. 과거 학습 날짜를 추측하거나 커밋 날짜를 조작하지 마.
- 누적 점수는 score의 합계야. 전체 만점·진행률은 계산하지 않아. 한국시간 커밋 날짜별 변화는 자동 집계되므로 별도 이력 파일이나 `study/data.json`을 수동 편집하지 마.
- 기존 파일을 보존하며 커밋하고 자동 배포 성공을 확인해. 결과 주소는 https://azza999.github.io/study/ 이야. 오늘 바뀐 주제·점수·누적 점수를 짧게 알려줘.
