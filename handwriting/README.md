# 한 글 한 글 · 필사 연습장

주소: https://azza999.github.io/handwriting/

기존 Jekyll 블로그 안에서 독립적으로 실행되는 정적 웹 앱입니다. HTML에 front matter를 넣지 않아 블로그 레이아웃을 적용하지 않습니다. 루트에 `.nojekyll`을 추가하지 마세요.

글·글꼴 선택, TXT 및 글꼴 업로드, 원고지 보조선, A4 인쇄와 PDF 다운로드를 지원합니다. 모든 처리는 사용자 브라우저에서 실행되며 업로드한 글/글꼴과 설정은 localStorage에 저장됩니다. 외부 API와 CDN을 사용하지 않습니다.

TXT: UTF-8, 최대 100KB 및 12,000자. 글꼴: TTF/OTF/WOFF/WOFF2, 최대 2MB. 브라우저 저장 공간 부족 시 알림을 표시합니다. 브라우저 데이터 삭제 시 저장된 내용도 사라집니다. PDF는 240dpi 이미지 기반입니다.

기본 연습 문장은 이 앱을 위해 작성했습니다. 나눔 글꼴은 Google Fonts 저장소에서 가져왔으며 각 라이선스는 `assets/fonts/OFL-*.txt`에 포함됩니다.

참고 양식: https://drive.google.com/drive/folders/1rvz3ofRQvOiztMUFl-o5Fnl6IynFWFOX
참고 이미지: https://edgio.clien.net/F01/9795949/1e625e2bc488b4.jpg?scale=width:740
참고 자료의 원본 파일은 재배포하지 않습니다.

줄 구성에서 **따라쓰기만**을 선택하면 진한 원문 줄 없이 입력한 글이 옅은 글씨로 한 번씩 이어집니다. 따라쓰기 진하기 설정은 미리보기·인쇄·PDF에 동일하게 적용됩니다.
